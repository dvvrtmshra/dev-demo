# Finger Gesture Detector 

Ek fun computer vision project jisme webcam se **haath detect hota hai**,  
**fingers count** hote hain.

---

## 🔥 Features
- 📸 Live webcam hand detection  
- ✋ Finger counting (0–5)   
- ⚡ Real-time output using OpenCV + MediaPipe  

---

## 🛠 Tech Stack
- Python 🐍  
- OpenCV  
- MediaPipe
